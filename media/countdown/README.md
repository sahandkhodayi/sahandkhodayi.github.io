# Countdown media

Assets used by the temporary LARPSOCIETY 12-day release countdown on `main`.

- `photo-01.svg` — primary LARPSOCIETY image
- `photo-02.svg` — secondary system image

The images are wrapped as SVG files so they can be committed through the repository API while preserving the uploaded JPG artwork.

To change the countdown artwork later, replace these two files and keep the filenames, or update the image paths in `index.html`.
